# Linguagens
Este repositório abriga uma pequena coleção de ambientes de linguagens de programação.

## Sobre o repositório

O repositório **Languages** reúne projetos voltados ao estudo e implementação de linguagens de programação clássicas e seus respectivos
ambientes de desenvolvimento. Eventualmente poderá ser definida nesta coleção projetos próprios de estudo e desenvolvimento.

Entre os projetos desenvolvidos encontram-se:

-   interpretadores;
-   compiladores;
-   montadores (assemblers);
-   analisadores léxicos, sintáticos e semânticos;
-   bibliotecas de execução (runtime);
-   bilbiotecas de apoio operacional (propostas próprias).

Os projetos aqui disponibilizados têm diferentes objetivos, abrangendo
pesquisa, ensino, experimentação e desenvolvimento de tecnologias
próprias.

------------------------------------------------------------------------

## Modelo de disponibilização

Este repositório adota diferentes modelos de distribuição para seus
projetos.

Alguns projetos são disponibilizados integralmente como **software de
código aberto (Open Source)**, permitindo acesso completo ao
código-fonte.

Outros projetos são publicados apenas em formato binário, documentação
técnica ou demonstrações de uso, mantendo parte ou a totalidade do
código-fonte restrita. Essa decisão pode decorrer de fatores como:

-   proteção de propriedade intelectual;
-   desenvolvimento em andamento;
-   futuras publicações técnicas ou científicas;
-   utilização em projetos comerciais ou educacionais.

Cada projeto informa claramente seu modelo de distribuição em sua
documentação específica.

------------------------------------------------------------------------

## Objetivos

Este repositório tem como finalidade:

-   pesquisar novas técnicas de implementação de linguagens;
-   desenvolver ferramentas para ensino de compiladores e
    interpretadores;
-   experimentar novos paradigmas de programação;
-   documentar arquiteturas e decisões de projeto;
-   disponibilizar material técnico para estudantes, pesquisadores e
    desenvolvedores.

------------------------------------------------------------------------

licenciamento e disponibilidade do código-fonte.
